# Funding the project

This project is sustained by [Unredacted](https://unredacted.org) a 501(c)(3) (US public charity). Donations are tax-deductible in the United States.

Donations fund the engineering hours behind the project & the [CVE response SLA](cve-policy.md): tracking upstream `linux-hardened` releases, rebuilding and publishing within 48 hours of high-severity CVE-fixing tags, and running the build infrastructure (Forgejo host, build host, Fastly egress).

- Test release candidates on hardware you have.
- Maintain a translation of the user docs.
